%% ---------- 專題研究 ----------
\autosection{專題研究}{RESEARCH}

我與教授共同進行的文獻探討，主題是不可分割物品的公平分配（Fair Division of Indivisible Goods）：當物品相對於總價值變得「微小」時，EF1（Envy-Free up to one item）分配所能保證的納什社會福利（Nash Social Welfare, NSW）能提升到什麼程度。

在相同可加性估值（identical additive valuations）下，已知 EF1 分配的 NSW 至少是最佳解的 $e^{-1/e}\approx 0.692$ 倍。我們探討的定理在物品滿足 $\epsilon$-小物品條件時，給出更強的下界 $\max\{e^{-1/e},\,\rho_n(\epsilon)\}$。其中 $\rho_n(\epsilon)$ 刻劃了 EF1 與小物品限制下最不平均的價值分佈：有 $k$ 人拿到略低於平均的 $\left(1-\frac{k\epsilon}{n}\right)$ 份額，其餘 $n-k$ 人拿到略高於平均的 $\left(1+\frac{(n-k)\epsilon}{n}\right)$ 份額，由此推得保證值隨 $\epsilon$ 變小而趨近最佳分配。

這份研究讓我學會如何閱讀論文、拆解證明結構，並將直覺轉化為可驗證的數學敘述，也讓我確認自己對理論與演算法設計的興趣。

%% ---------- 個人特質與展望 ----------


\autosection{背景與興趣}{BACKGROUND}

大學階段我完成三個較完整的專案，它們的共同結構是\textbf{長序列決策，且合法動作集合隨狀態改變}：

\begin{itemize}
	\item \textbf{Pokémon TCG 決策代理人（模仿學習）：}把一局對戰視為 behavior cloning 問題。以 Transformer 編碼 46 個狀態 token（手牌、場上寶可夢、能量、棄牌堆等），輸出端不是固定維度的 softmax，而是 pointer-style 的 scoring head——對\textbf{當下動態枚舉出的合法動作}逐一打分，因此動作空間大小每步都不同。以數百萬個決策點訓練，資料層用 memory-mapped shard 搭配 GPU 端特徵組裝維持 data loader 吞吐，訓練採 bfloat16、EMA 與 Muon optimizer。兩個牌組的 specialist 相對基準的動作準確率提升 \textbf{+20.5\% acc}，並實際接上官方 C++ 引擎完成競賽部署。
	\item \textbf{Orbit Wars 策略代理人（搜尋與規劃）：}環境是持續移動的軌道幾何。我把「攻擊哪顆行星」化為解 ETA 攔截、再以抵達時守軍、敵方增援風險與產能估計 ROI 的多波次貪婪規劃，正式推論以 Rust 重寫以換取每回合更多的搜尋量。
\end{itemize}

\vspace{6pt}
兩個專案讓我反覆撞到同一件事：當序列很長、動作空間又有結構時，
純 end-to-end 很難只靠 reward 或 label 學起來，
最後都得把先驗以\textbf{結構}的形式放進模型外圍——合法動作枚舉、ETA 的解析解、EF1 遮罩。\
我想研究的正是這條界線：\textbf{強化學習能讓模型學會多少、哪些該由外層的 harness 保證以及嘗試探索搜尋如何幫助模型推論}，近年強化學習似乎還有很多問題沒有解決，甚至許多都只能靠外部系統去阻止，但或許強化學習還有許多潛能可以探索，以及或許推論時加上搜尋如何影響決策品質與推論成本。


%% ---------- 讀書計畫 ----------
\autosection{讀書計畫}{STUDY PLAN}

我的研究興趣集中在\textbf{序列決策及強化學習}：如何讓模型在動作很多、又必須一步步決定的問題上做得更好。大學期間的三個專案已經讓我摸到這條線的兩端——訓練端與推論端，我想在碩士階段把它們接起來：\textbf{訓練時的 optimizer 不只決定模型收斂到哪裡，也可能決定這個模型適不適合在推論時被搜尋利用}。以下是我為此規劃的進度。

\begin{itemize}
\item 補強數值線性代數（矩陣分解、矩陣函數的迭代近似）與最佳化理論——這是理解 Muon 的 Newton--Schulz 正交化與各類 preconditioner 的前提。

\item 持續閱讀序列模型文獻，掌握近期的模型架構與研究方向，例如 Mamba 等 state-space models，並比較其與 Transformer 在長序列建模、推論效率及記憶體成本上的差異。

\end{itemize}
